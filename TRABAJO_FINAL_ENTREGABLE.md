## Descripción
Landing Page funcional con HTML5/CSS3/JS + PHP 8.3 + SQLite. Presenta solución, características, casos de uso y formulario de contacto con comunicación cliente-servidor.

## Funcionalidades
- Diseño responsive
- Menú móvil interactivo
- Validación cliente y servidor
- API REST /api/leads.php (POST/GET)
- Almacenamiento en SQLite
- Comunicación AJAX/Fetch
